# DocuLens AI -- Frontend

A minimal React + TypeScript web UI for DocuLens AI.

## Quick Start

```bash
npm install
npm run dev
```

The app expects the backend API at http://localhost:8000.

## Stack

- React 18
- TypeScript
- Vite
